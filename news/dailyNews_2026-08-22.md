### [Cloudflare 推出缓存响应规则，提升缓存控制灵活性](https://www.infoq.cn/article/kyUdCw0IPHwuIHg2WJCu)

来源：InfoQ 推荐

发布时间：2026-08-22 17:17:00

Cloudflare 推出了缓存响应规则（Cache Response Rules），为用户提供了细粒度的缓存控制。这一新功能允许在内容写入缓存之前检查及修改源站返回的 Header，优化缓存命中率并降低源站负担。本功能支持移除如 Set-Cookie 等影响缓存的 Header，管理 Cache Tag，并修改 Cache-Control 指令，而无需修改源站代码。官方强调这种规则补充了已有的缓存规则，各自负责处理不同阶段的问题。这一技术革新显著提升了在复杂场景下的缓存管理灵活性，但也有部分从业者对误操作可能带来的风险表示担忧。目前，功能已面向所有套餐开放，进一步帮助开发者在边缘侧灵活优化缓存策略。

### [npm 12 发布：全面加强的安全默认策略](https://www.infoq.cn/article/fPGPEF2hwCKtz3PTg69C)

来源：InfoQ 推荐

发布时间：2026-08-22 11:05:00

GitHub 宣布推出 Node.js 的新版本包管理器 npm 12，其中带来了大幅的安全改进。新版本默认禁用 allowScripts，阻止依赖项的自动执行安装脚本以及某些非注册表来源，如 Git 和 HTTPS tarball。这种变化旨在减少潜在的攻击面，增强开发项目的安全性。不过，这些新策略可能带来构建失败或审批疲劳的问题，引发社区热议。开发者既表达了对提高安全性的支持，也对特定场景中的不便提出质疑。此外，npm 12 还为开发者提供了更透明和细化的脚本管理策略，相比其他软件包管理器，如 pnpm和yarn，着眼于提高用户体验的定制化。总的来说，此次更新标志着 npm 在生态系统中的重要演变。

本文探讨了近年来外资餐饮品牌在中国区业务逐渐本土化的现象，例如麦当劳、星巴克等知名品牌将运营交由中资团队管理。文章详细分析了餐饮行业本土化的原因，外资品牌在中国市场的经营困境，以及具体的产品、价格和门店模型调整策略。此外，通过案例研究，揭示了如星巴克的门店音乐本地化、柠季接管哈根达斯亏损门店等细节，指出本土化的细微变化如何影响品牌发展。同时，本文对比了餐饮业与其他行业的本土化差异，提出技术、终端品牌和需求等因素对行业主导权的重要性，值得关注和深思。

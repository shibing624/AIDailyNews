### [OpenSmith：LangSmith 的本地开源替代方案](https://github.com/shivnathtathe/opensmith)

来源：Hacker News - Newest: "llm"

发布时间：2026-07-26 22:36:47

OpenSmith 是一个提供本地化、隐私优先的 LangSmith 替代方案，支持离线安装和使用，无需云服务或账户配置。用户可以使用 pip 安装，并选择支持 OpenTelemetry 和 Postgres 的扩展功能。工具允许对 Python LLM 管道的跟踪进行本地检查，所有跟踪数据保存在本地，无需上传云端，保证了数据隐私。配置文件读取简单，支持通过浏览器在本地查看仪表盘，并支持 JSON、CSV 格式的跟踪导出。此外，工具还集成了 OpenTelemetry 用于跟踪和监控。OpenSmith 特别适合有隐私需求或对敏感数据处理严格要求的用户。

来源：Hacker News - Newest: "llm"

发布时间：2026-07-26 13:57:24

本文探讨了大语言模型（LLM）评估系统中的两个主要噪声来源：输入的歧义性和评估者的非一致性。作者描述了统计噪声对评估结果的影响并指出，许多人存在将动态估算指标误作为固定分数的误解。为提升模型评估的可靠性，应采用更精确的输入及稳定的评估机制，避免运行不稳定或非确定性导致的偏差。此外，文章提出了创建更可靠评估架构的建议，包括使用信号区间而非追求绝对正确性，设计多样性验证策略等，其目的在于建立一个信任机制，从而减少对偶然分数变动的盲目追逐。

### [jcode：高效可定制的编程代理工具](https://github.com/1jehuang/jcode)

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-07-27 00:06:23

jcode 是下一代编程代理工具，专为支持多会话工作流和高度可定制性而设计。它优化了资源效率，降低了内存使用（单会话消耗仅27.8MB），并提供快速响应时间（首次输入延迟仅为48.7毫秒）。其主要特点包括语义内存系统、超快的渲染和滑动性能、自定义滚动条实现以及针对多种语言的支持，用户可以通过边栏查看和实时更新文件或图表。该工具适合需要高性能的开发者，尤其是在复杂项目中，jcode 的图形化界面和模块化设计带来了更高的工作效率，且适配性强，减少了使用场景下的资源浪费。

### [移动设备验证工具 (MVT)](https://github.com/mvt-project/mvt)

来源：Trending Python repositories on GitHub today · GitHub

发布时间：2026-09-23 02:33:03

Mobile Verification Toolkit (MVT) 是由国际特赦组织安全实验室开发的一套工具，用于简化和自动化收集帮助识别 Android 和 iOS 设备可能遭到入侵的法证迹象。MVT 支持使用公开的威胁指标扫描移动设备，以检测已知间谍软件活动的潜在痕迹。尽管这些公开指标不能保证设备安全、未被攻击，但它提供了有助于深入分析和三角评估的工具。推荐有经验的数字法证专家使用，而非普通用户自我评估。MVT 可以通过源代码或 PyPI 安装，可以生成 Bash、Zsh 和 Fish 的shell完成脚本。

### [WeKnora: 企业级文档理解框架](https://github.com/Tencent/WeKnora)

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-09-23 02:33:08

WeKnora是一个开源的LLM驱动知识框架，旨在企业级文档理解、语义检索和自主推理。其核心功能包括RAG快速问答、ReAct Agent自动编排检索、MCP工具、技能目录及文本语料库管理等。WeKnora能够将分散的文档转化为可查询、具备推理能力的动态知识资产，支持多平台操作，并且具备全面的数据主权保护。最新版本包括技能沙盒运行时、跨会话长期记忆、多种文档格式处理及全面的可观测性工具集成，适用于复杂的多步骤任务自动化处理。

### [BitChat：去中心化离线与全球信息通信工具](https://github.com/permissionlesstech/bitchat)

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-08-02 00:01:02

BitChat 是一款创新的点对点消息应用，采用双传输体系架构：蓝牙网状网络支持离线通信，Nostr 协议支持互联网全球通信。其特点包括无需账号、电话号码和服务器，完全去中心化。蓝牙传输保证了灾难场景下的本地通信，而 Nostr 协议支持基于位置的全球接入。功能如端到端加密、智能消息路由和位置频道使其在隐私与功能兼备方面表现突出。此外，BitChat 提供便捷的安装验证机制，提高了安全性与可信度。应用重点强调隐私保护，例如支持设备标识加密以及紧急数据擦除功能，非常适合需要高隐私通信的用户群体。

### [Buzz：人类与 AI 的协作工作空间](https://github.com/block/buzz)

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-08-02 00:01:02

Buzz 是一个自托管的工作空间，专为人类与 AI 代理协作设计。Buzz 使用 Nostr 协议，通过一个关键的事件日志统一记录团队操作，如消息、代码审查、工作流以及 Git 事件等。用户和 AI 代理共享工作台，可分担任务如代码合并、错误筛选和发布文档等。Buzz 提供独特的功能，例如将特性分支和工作流整合至一个频道，支持所有记录可搜索、可审计，且通过 Rust 技术栈构建高性能底层架构。此外，Buzz 的多租户部署和事件记录让团队操作更加高效和透明，特别适合专注于协作和高效团队管理的开发者。

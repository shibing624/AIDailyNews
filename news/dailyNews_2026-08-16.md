### [宏环肽药物与AI在药物研发中的角色](https://www.empirical.health/blog/macrocyclic-peptides/)

来源：Hacker News - Newest: "AI"

发布时间：2026-08-16 23:07:05

文章介绍了宏环肽作为一种新药物类别，其介于传统的小分子药物和生物制剂之间，兼具两者的优点。重点讨论了首个口服PCSK9抑制剂Enlicitide的研发过程，历时13年并未使用AI。这一药物能够以片剂形式降低约60%的低密度脂蛋白胆固醇（LDL），其开发过程分为四个阶段，包括分子筛选、结合活性增强、通过肠壁吸收以及大规模生产。虽然AI在早期分子设计和最后的生产优化环节上表现出潜力，但在优化结合活性和提升生物膜渗透性上仍有明显不足。文章不仅展示了药物研发的挑战，还探讨了AI在新药发现中的潜在价值及现存的局限性，值得相关领域的专业人士参考和借鉴。

### [LittleLearner：在固定知识范围内探索语言模型学习能力](https://littlelearner-ll.github.io/)

来源：Hacker News - Newest: "llm"

发布时间：2026-08-16 15:37:53

LittleLearner是一个语言模型研究项目，它专注于通过严格的知识范围控制来研究模型的学习能力。模型仅基于一个88B-token的语料库进行训练，该语料库经过了与美国K-5年级课程标准一致的多阶段过滤，仅包括小学知识。这个模型在多个规模下（0.6B、1.3B、5B）被训练和对照实验，分析了模型在受控知识暴露条件下的反应与局限性。实验表明，尽管放大量或后期训练可提升模型在既定范围内的能力，但对超出范围的问题并无显著改善。此外，研究还发现，预训练的过滤设置实质上决定了模型的能力上限。文中还探讨了受控训练对RL过程和行为研究的潜在价值，包括模型对新增概念的反应以及在知识边界附近的行为特征。项目为研究语言模型如何透过明确的知识范围学习提供了一个干净的实验平台，为未来人类与模型学习行为的比较研究奠定了基础。

### [Spotify推出低延迟数据湖查询框架RAP](https://www.infoq.cn/article/iRjDa2ayZ9KLUtWylQZl)

来源：InfoQ 推荐

发布时间：2026-08-16 10:00:00

Spotify 推出了 Random Access Parquet（RAP），一种在现有 Apache Parquet 文件之上增加外部索引的新架构，从而优化低延迟点查询，避免将数据集复制到操作型数据库。此创新使得数据湖的点查询效率显著提高，同时保持了与现有数据格式的兼容性，并降低了数据重复的成本。RAP 的外部索引可实现快速定位，避免扫描海量文件，而数据尤其适用于分析处理和对延迟敏感的AI应用场景。文章还探讨了二级索引、交错排序等优化策略，以及与类似Google Cloud新湖仓架构的比较和应用场景的社区讨论。这篇文章为希望提升数据湖操作性能的开发者提供了宝贵的技术思想。

来源：Trending Python repositories on GitHub today · GitHub

发布时间：2026-08-16 23:20:58

Needle 2是一款仅45M参数的小型AI模型，具有高效工具调用、设备使用和结构化数据提取能力。尽管体积小，它在基准测试中与多款更大的模型性能相当乃至超越。Needle 2基于简单注意力网络架构，支持LoRA微调，与Hugging Face集成，整个模型仅为单个14MB的二进制文件，占用28MB内存。其特点包括内嵌权重文件、自主工具描述、多轮上下文对话，以及高效内存策略（256-token滑动窗口）。模型支持在NVIDIA GPU和Apple Silicon设备上进行快速训练或部署，对资源有限的设备尤为友好。

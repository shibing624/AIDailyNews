### [{fmt}: 提供快速安全的C++格式化库](https://github.com/fmtlib/fmt)

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-09-09 02:19:23

{fmt} 是一个开源格式化库，为C stdio和C++ iostreams提供了快速安全的替代方案。支持简单的格式API、实现C++20的std::format和C++23的std::print，兼容Python风格的格式字符串。其核心优势包括高性能和节省代码、便携的Unicode支持、类型安全并具有强大的扩展性。特别是其基于Dragonbox算法实现的IEEE 754浮点格式器，确保了正确舍入和高效率。{fmt}库被包括MariaDB、PyTorch和Windows Terminal等知名项目采纳，具备极低编译时间和小型二进制文件体积。该库还提供跨平台一致性和清晰的文档。

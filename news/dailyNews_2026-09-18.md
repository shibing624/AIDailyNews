### [AI机器拯救2500万块乐高积木：环保与技术创新的结合](https://www.bbc.com/news/articles/c689jqvnqw9jo)

来源：Hacker News - Newest: "AI"

发布时间：2026-09-18 01:52:11

### [开源代码审查工具Open Code Review](https://github.com/alibaba/open-code-review)

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-09-18 02:50:54

Open Code Review是一个由阿里巴巴集团开发的AI驱动代码审查CLI工具，已经从内部项目转变为开源项目。它通过Git diff读取更改文件，并将其发送到可配置的大型语言模型（LLM），生成结构化审查评论。相比于一般用途的代理，Open Code Review在使用相同模型时精度和F1评分均明显较高，同时消耗的tokens约为其1/9，审查时间更快。核心设计结合了确定性工程和代理混合，通过精确文件选择、智能文件捆绑等方式确保审查步骤正确。适用Git >= 2.41，支持多种安装和配置方式，以实现快速启动和审查等高级功能。

### [结构化代码错误检测工具：Tracelint](https://github.com/AshwinUgale/tracelint)

来源：Hacker News - Newest: "llm"

发布时间：2026-08-18 22:49:47

Tracelint 是一个专注于结构化代码错误检测的工具，能够通过 JSON 格式的执行轨迹文件检测常见问题，如结构性错误、被忽略的错误、模式违反和循环等，无需依赖语言模型进行判断。不同于传统的 AI 方法，它不需要任何 API 密钥或模型下载，直接脱机运行并输出错误诊断结果。Tracelint 支持多种输入格式，并可以转换不同来源的日志结构以便统一检测，是一款轻量级的工具，兼容 JSON 和 JSONL 格式，以及多种日志类型，如 OpenAI 消息、Langfuse 轨迹或 OpenTelemetry 数据。工具提供了修复指标，通过基于轨迹的故障注入和恢复测试，评估程序在特定条件下的表现。其核心代码依赖有限，适用 Python 3.10-3.12。总体来看，Tracelint 提供了高效的错误检测机制，适合 CI/CD 工作流中的代码质量保障。

### [学术欺诈：LLM生成文章中的错误引用现象](https://jilltxt.net/misaligned-citations-and-llm-generated-scientific-fraud/)

来源：Hacker News - Newest: "llm"

发布时间：2026-09-21 00:02:41

本文探讨了LLM（大规模语言模型）生成的学术文章中常见的引用错误及其背后的原因。作者举例说明某些文章存在无关引用的现象，并深入分析了这种错误如何系统性地产生。从描述中可以看出，一些AI生成的文章虽然表面看起来引用了相关文献，但深入分析后发现引用的是与主题不相关的文献，例如用一篇探讨数字临时性的文章引用了错误的研究成果。作者批评了这种现象，并提出要提高AI读写能力以避免此类问题。这种现象不仅影响学术文章的可信度，还削弱了研究价值。作者呼吁读者关注并报告类似的错误引用现象，以推动学术界对AI生成内容的规范化。

来源：Trending repositories on GitHub this week · GitHub

发布时间：2026-09-21 01:58:27

Open Code Review是一个AI驱动的代码审查CLI工具，最初作为阿里巴巴集团内部的官方AI代码审查助手，现已开源。它通过配置模型端点读取Git差异，通过代理发送更改文件到可配置的LLM，并生成精确的结构化审查评论。该工具不仅可以审查差异，还可审查整个文件，在大型代码库中识别代码缺陷且稳定性高。此外，与通用代理相比，Open Code Review在精度和F1指标上显著更高，且消耗的tokens只有大约1/9。它通过智能文件选择、文件打包和细粒度规则匹配来确保评审过程的准确性，并通过动态决策提高评审效率。适用于Git, CLI安装后即可开始使用，通过文档进一步了解详细操作步骤和配置。

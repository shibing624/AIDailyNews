### [Kubernetes Agent Sandbox: 为长生命周期容器提供标准化API](https://github.com/kubernetes-sigs/agent-sandbox)

来源：Hacker News - Newest: "AI"

发布时间：2026-08-01 00:16:53

Agent Sandbox是Kubernetes SIG Apps开发的一个用于管理长生命周期、状态化工作负载的自定义资源定义（CRD）和控制器。它引入了Sandbox CRD，以声明式API形式支持单实例容器的稳定标识和持久存储需求，类似轻量虚拟机体验，解决了传统Deployment和StatefulSets在特定工作负载场景下的局限性。此外，扩展模块提供高级功能如模板化和资源池，支持通过Go或Python SDK进行编程交互。项目针对供应商中立性设计，适用于AI agent运行时等场景，并具备详细的安全模型和高效社区支持，是提升复杂 Kubernetes 应用管理效率的重要工具。

### [跨多平台的 AI 搜索引擎：/last30days 带来的创新](https://github.com/mvanhorn/last30days-skill)

来源：Trending Python repositories on GitHub today · GitHub

发布时间：2026-08-01 00:46:21

/last30days 是一个由 AI 驱动的搜索引擎，通过 Reddit、X、YouTube、GitHub 等多个平台的数据结合用户行为信号（点赞、评论、交易市场数据等），提取过去30天内的热门内容并进行评分。与传统编辑驱动的搜索引擎不同，它提供实时、跨平台的内容汇总和结论。该工具不依赖单一平台 API，而是通过用户提供的密钥和会话跨平台组合数据。典型应用包括了解即将见面的CEO最近动态、发现早期趋势以及比较技术工具。这种基于用户实际互动与信息相关性的搜索模式，为用户提供更直观和语境化的信息聚合，避免信息孤岛的困扰。同时，它将开放 API 和多平台访问整合于一体，为开发者提供了强大的扩展可能性。
